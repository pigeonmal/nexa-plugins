# nexa-plugins

Official plugin packages for [Nexa](https://github.com/pigeonmal/nexa).

## Packages

| Package | Description |
|---|---|
| [`@nexa/video-player`](video-player) | Native AVPlayer and Media3 playback, HLS on iOS, HLS and DASH on Android |
| [`@nexa/mmkv`](mmkv) | Synchronous key-value storage over MMKV, with encryption, typed generics, and change listeners |
